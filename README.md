# Dashboard Hospitalar

## Objetivo

Projeto desenvolvido para prática de análise de dados na área da saúde utilizando Power BI.

## Ferramentas Utilizadas

- Power BI
- Excel

## Indicadores Analisados

- Indicadores assistenciais
- Informações operacionais
- Métricas hospitalares
- Acompanhamento de desempenho

## Resultado

O dashboard foi desenvolvido para consolidar informações e facilitar a visualização de indicadores relevantes para gestão e acompanhamento operacional.

## Aprendizados

Durante este projeto pratiquei conceitos de modelagem de dados, criação de métricas e visualização de informações em contexto hospitalar.
